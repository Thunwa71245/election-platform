## 6. เกณฑ์รับงานและการตรวจด้วยมือ

- ครอบคลุม D1–D10: ผ่านด้านการตรวจเอกสาร ไม่ใช่ด้าน implementation
- จำกัดการเปลี่ยนแปลง: ผ่านตามคำสั่งผู้ใช้ (AGENTS.md + docs/); เกณฑ์ P0 แบบ “ไม่มีไฟล์นอก docs/” มีข้อยกเว้น AGENTS.md ที่ผู้ใช้สั่งโดยตรง
- ระบุคำสั่ง build/test จริงและผล: บันทึกแล้วว่าไม่มีและเป็น N/A; ไม่สามารถรับรอง build/test ผ่าน
- SPEC §8 ต้องให้ทีมตัดสิน keep/refactor/replace: มีข้อเสนอแล้ว แต่การยืนยันแนวทางและ stack ยังรอทีม ไม่ถือว่า exit gate นี้ได้รับการยืนยัน

- ความเสี่ยง: ยังไม่มีต้นแบบตรวจพฤติกรรม ขนาดงานเป็นประมาณการ และกติกา/ข้อมูล/ความลับบางส่วนยังไม่ยืนยัน ไม่มีหนี้โค้ดที่ตรวจพบเพราะไม่มีโค้ด
- ตรวจด้วยมือ: รันคำสั่ง inventory ข้างต้น เปิด AGENTS.md เทียบ MASTER PROMPT และตรวจตารางกับ SPEC §1; ไม่มีบัญชีตัวอย่างหรือขั้นตอนกด UI ในระยะนี้
