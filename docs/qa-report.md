## 2. สิ่งที่ทดสอบผ่าน

**ทั้งสองขนาดจอ**
- 17 หน้าจอหลักต่อขนาดจอ (หน้าแรก, login, รายการสิทธิ์, บัตรเลือก 1 และ 2 คน, modal ประวัติ, modal ยืนยัน, ภาพรวมผู้ดูแล, รายละเอียดหน่วย, editor, ผู้มีสิทธิ์, นำเข้า, ผลคะแนน, ประวัติ, รหัสสำรอง, preview) ไม่มีการล้นแนวนอน และมีแถบ "ต้นแบบ — ข้อมูลสมมติ ไม่ใช่การลงคะแนนจริง" ทุกหน้า
- แถบจำลองที่ fixed ด้านล่างไม่บังเนื้อหาส่วนท้ายเมื่อเลื่อนสุด; รูปผู้สมัครขนาดเท่ากัน (85×100 บนมือถือ)

**แยกส่วนสมาชิก/ผู้ดูแล**
- หน้าแรกมีลิงก์ `#/user/login` และ `#/admin/login` แยกกัน; หน้าสมาชิกไม่มีลิงก์/เมนู/ปุ่มผู้ดูแล
- session สมาชิกเข้า `/admin` ไม่ได้ (ต้อง login ผู้ดูแล); logout ผู้ดูแลไม่ทำให้สมาชิกหลุด

**เข้าสู่ระบบ**
- ขอรหัส: ปุ่มแสดง "กำลังดำเนินการ…" แล้วแสดงช่องทางแบบปิดบังและรหัสจำลอง
- login โดยไม่ขอรหัสก่อน → "รหัสผิด"; รหัสผิด → "รหัสผิด กรุณาตรวจสอบรหัสเข้าใช้"; ผิด 5 ครั้ง → "ถูกล็อกชั่วคราว"
- รหัสหมดอายุ: ทั้งตัวเลือกจำลอง และ**เวลาจริงผ่าน fake clock 5 นาที** → "รหัสหมดอายุ กรุณาขอรหัสใหม่"
- 000127 (ไม่มีช่องทาง) ถูกแนะนำให้ติดต่อ helpdesk; helpdesk ออกรหัสสำรอง → login ได้ และรหัสใช้ได้ครั้งเดียว
- ผู้ดูแลรหัสผ่านผิดถูกปฏิเสธ

**ลิงก์หน่วยและสิทธิ์**
- เปิด `#/user/u/{publicId}` ก่อน login → แสดง "เข้าสู่ระบบแล้วจะกลับหน่วยเดิม" → login แล้วกลับหน่วยเดิม; ก่อน login ไม่มีชื่อผู้สมัครใน DOM
- 000126 (ไม่มีสิทธิ์) และ 000123 เปิดหน่วยสาขา (มีสิทธิ์หน่วยอื่น) → "คุณไม่มีสิทธิ์ลงคะแนนในหน่วยนี้" + "ดูหน่วยที่ฉันมีสิทธิ์" และไม่มีข้อมูลผู้สมัครใน DOM
- publicId ไม่มีจริง / การเลือกตั้งฉบับร่าง → ข้อความเดียวกัน "ไม่พบหน่วยลงคะแนน หรือยังไม่พร้อมใช้งาน"
- publicId เป็น UUID สุ่ม ไม่ใช่ id ลำดับหรือชื่อหน่วย

**รายการสิทธิ์** (ทุกบัญชีตัวอย่างตรงตาม README)
000123=1 กำลังเปิด, 000124=2 คนละการเลือกตั้ง, 000125=ใช้สิทธิ์แล้ว, 000126=0 พร้อม empty state, 000901 หน่วยเล็ก, 000902 ยกเลิก, 000903/000905 ปิดหีบ, 000904 ยังไม่เปิด, 000906 ประกาศแล้ว (แสดงผู้ชนะ ไม่แสดงคะแนน), 000907 ฉบับร่าง=0; เวลาแสดงแบบ Asia/Bangkok ปี พ.ศ.

**การลงคะแนน**
- บัตร 1 คน: แตะการ์ด (รวมถึงกด Enter ด้วยคีย์บอร์ด) เปิดป๊อปอัปยืนยันทันที มีรูป หมายเลข ชื่อ ข้อความยืนยัน และ "เมื่อส่งคะแนนสำเร็จแล้วจะเปลี่ยนไม่ได้"
- "กลับไปเลือกใหม่" ปิดป๊อปอัป, เปลี่ยนผู้สมัครแล้วป๊อปอัปแสดงคนใหม่เท่านั้น, Esc ปิดป๊อปอัปได้เมื่อไม่ได้กำลังส่ง
- ไม่ประสงค์ลงคะแนน: ข้อความ "คุณต้องการยืนยันไม่ประสงค์ลงคะแนนใช่หรือไม่?" และล้างตัวเลือกผู้สมัคร (exclusive); ซ่อนเมื่อกติกาไม่อนุญาต (e1)
- บัตร 2 คน: ปุ่ม "ตรวจทานและยืนยัน" เปิดเมื่อครบ 2, คนที่ 3 ไม่ถูกเลือก, ป๊อปอัปแสดงทั้งสองคน
- ระหว่างส่ง: ปุ่มเป็น "กำลังส่งคะแนน…" + disabled, Esc/ปุ่มปิดใช้ไม่ได้
- สำเร็จ: กลับ `#/user`, toast "บันทึกคะแนนเรียบร้อยแล้ว" ไม่ระบุผู้สมัคร, การ์ดเป็น "ใช้สิทธิ์แล้ว" ไม่มีปุ่มลงคะแนน, เปิดลิงก์หน่วยซ้ำเห็นแถบเขียวและไม่มีผู้สมัคร, ปุ่ม Back ไม่เปิดป๊อปอัปซ้ำ
- ตัวเลือกไม่อยู่ใน URL / sessionStorage / eligibility (มีเฉพาะยอดรวม); คะแนนผู้สมัครที่เลือก +1, ballotCount +1
- กด "ยืนยันลงคะแนน" สองครั้งเร็ว ๆ → บันทึก 1 ครั้ง; สองแท็บส่งพร้อมกัน → บันทึก 1 ครั้ง (ข้อความผิด ดู QA-01)
- เครือข่ายขาดก่อน/หลังบันทึก: แสดง "ยังไม่ทราบผล…", ป๊อปอัปปิดไม่ได้, ตรวจสถานะ/ส่งใหม่ด้วยคำขอเดิมจบที่บันทึก 1 ครั้ง (idempotent)
- หีบปิดระหว่างเปิดป๊อปอัป → "หน่วยนี้ยังไม่เปิดหรือปิดหีบแล้ว" ไม่บันทึก
- สถานะเปิด/ปิดอิงเวลาจำลองกลาง เปลี่ยน `Date.now` ฝั่งเครื่องแล้วไม่มีผล

**ผู้ดูแล**
- สร้างการเลือกตั้ง: เวลาปิด ≤ เวลาเปิด, min > max ถูกปฏิเสธ; เผยแพร่ถูกกันด้วย checklist (ไม่มีหน่วย / มีหน่วยที่ขาดผู้สมัครหรือผู้มีสิทธิ์); ครบแล้วเผยแพร่ได้และสมาชิกใหม่เห็นทันที
- หน่วย: เพิ่มหน่วยได้, เวลา override (ปิด ≤ เปิด ถูกปฏิเสธ; ตารางและหน้าสมาชิกแสดงเวลาที่มีผล), ยกเลิกหน่วยต้องมีเหตุผล
- ผู้สมัคร: เพิ่ม/แก้, หมายเลขซ้ำในหน่วยถูกปฏิเสธทั้งตอนเพิ่มและแก้, หมายเลขซ้ำข้ามหน่วยได้, หมายเลข 0 ถูกปฏิเสธ
- ระหว่างเปิดหีบ: กติกาและเวลาเปิดล็อก, เพิ่ม/ลบผู้สมัครไม่ได้, ย่นเวลาปิดก่อนเวลาปัจจุบันไม่ได้, ขยายเวลาปิดต้องมีเหตุผล
- ผู้มีสิทธิ์: เพิ่มด้วยมือรักษาเลข 0 นำหน้า (`0007770`), กันสิทธิ์หลายหน่วยในการเลือกตั้งเดียวกัน, ลบสิทธิ์คนที่ใช้สิทธิ์แล้วไม่ได้
- election_admin เห็นเฉพาะการเลือกตั้งที่ได้รับมอบ

**นำเข้า Excel**

## 5. ข้อสังเกตที่ไม่ถือเป็นบั๊ก (ตรงกับเอกสารการตัดสินใจ)

- session ใช้ sessionStorage ไม่มี cookie (ADR-029); เปิดแท็บใหม่ต้อง login ใหม่
- เผยแพร่การเลือกตั้งที่เวลาปิดผ่านไปแล้วได้ทันที (มี E2E ยืนยันพฤติกรรมนี้) — ควรถามลูกค้าว่าต้องการคำเตือนหรือไม่
- ยกเลิกหน่วยแล้วคะแนนเดิมคงอยู่ (ADR-033) — ผลกระทบด้านความลับดู QA-03
- เครื่องมือผู้ทดสอบ (เครือข่ายจำลอง, รีเซ็ต) แสดงในหน้าสมาชิกด้วย เป็นเครื่องมือของต้นแบบ ต้องไม่ติดไปในระบบจริง
- แถบเครื่องมือที่ fixed ด้านล่างใช้พื้นที่ 76 px (สมาชิก) / 115 px (ผู้ดูแล) บนมือถือ 844 px แต่ไม่บังเนื้อหาส่วนท้าย
- ตารางผู้ดูแลบนมือถือเลื่อนแนวนอนในกล่องตาราง (ไม่ล้นหน้า) และป้ายสถานะคอลัมน์ขวาถูกตัดจนกว่าจะเลื่อน
